
# Project: Trip Planner

* **Title:** Trip Planner
* **Description:** A personalized travel itinerary generator utilizing the Geoapify Places API to create custom daily schedules, hotel booking links, and printable PDF exports.
* **Technologies:** Next.js, TypeScript, Material UI, Geoapify API
* **Link:** https://github.com/vedantbhamare-11/Trip-Planner

## Deep Dive & Architectural Context for AI Knowledge

I built Trip Planner to automate the tedious process of travel scheduling. Users input their duration, destination, and travel style, and the app generates a highly structured daily itinerary.

I integrated the Geoapify Places API to fetch categorized recommendations (entertainment, nature, heritage, etc.) and dynamically generate 4-5 locations per day. For the UI, I used Material UI and implemented a drag-and-drop interface so users can easily rearrange their schedules. I also added dynamic image fetching from Unsplash, direct hotel booking integrations (MakeMyTrip/Booking.com), and a robust PDF export feature for offline access.
