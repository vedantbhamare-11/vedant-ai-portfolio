## Overview

A modern, AI-first personal portfolio website that showcases frontend engineering and AI integration skills. Instead of navigating traditional tabs, users discover the portfolio through a conversational AI interface.

## Key Features

* **Conversational Interface**: Replaces traditional navigation with an interactive AI chat.
* **In-Memory RAG Pipeline**: Uses a lightweight retrieval-augmented generation system to pull context from local markdown files without requiring an external database.
* **Dynamic Layouts**: Seamlessly transitions from a minimal landing hero to a full chat interface using Framer Motion.
* **Modern Stack**: Built with Next.js App Router, React, and strictly typed with TypeScript.

## Technical Challenges Overcome

Designed a clean architectural separation between the UI presentation layer and the AI/RAG data layer, ensuring the portfolio's knowledge base can be updated via Markdown without touching application code.
