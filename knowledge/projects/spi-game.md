
# Project: SPI Game

* **Title:** SPI Game
* **Description:** A browser-based multiplayer strategy simulation game mimicking the biological processes of birth, reproduction, and mortality within a competitive digital ecosystem.
* **Technologies:** JavaScript, HTML5, CSS, Custom Game Engine
* **Link:** https://drive.google.com/file/d/1E50ZcTTCGdU-7QJAog6ffIHoD4XDnsJg/view

## Deep Dive & Architectural Context for AI Knowledge

I built the "SPI" game entirely from scratch to explore life simulation, resource management, and strategic survival mechanics. Instead of using a pre-built framework, I engineered a custom game logic engine using vanilla JavaScript, HTML5, and CSS.

The game allows multiple players to compete on a single device. Each player starts with a single entity (a "Spi") and must carefully manage their energy and spatial resources to reproduce, move, and dominate the digital ecosystem while avoiding mortality. It requires intense strategic balancing, as the game dynamically evolves until only one species outlasts the competition.
